# 🧓 SilverConnectPPL

**SilverConnectPPL** is a conceptual system design for a modular application intended to support elderly users in navigating digital services with ease and clarity. This repository documents the **software architecture** and application of key **object-oriented design patterns**, developed as part of a university-level Software Engineering Project (*Proyek Pengembangan Perangkat Lunak*).

---

## 📌 Project Purpose

This project focuses on demonstrating how thoughtful software architecture and the application of classical design patterns—namely the **Facade** and **State** patterns—can lead to a more maintainable, scalable, and modular software system.

Although no functional application is implemented, the structure reflects real-world considerations in system design and modular service communication.

---

## 🧩 Key Design Patterns

### 🧱 Facade Pattern  
Implemented via `main.py`, which serves as a unified entry point to various subsystems (services). This pattern provides a simplified interface, hiding the complexity of internal modules such as authentication, chat, notifications, and user settings.

### 🔄 State Pattern  
Used in selected services (e.g., notifications, authentication) to manage internal behavior based on user or system state. The pattern encapsulates state logic, enabling dynamic transitions and behavior changes without bloating the core logic.
